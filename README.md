# HTML-JavaScript
HTML JavaScript CSS 实现的一些效果
可以打开主目录下的index.html文件进行预览

## 服务器部署

本项目现在支持通过 Node.js 服务器进行部署，提供更好的访问体验。

### 快速启动

```bash
# 安装依赖
npm install

# 启动服务器
npm start
```

然后在浏览器中访问 `http://localhost:3000`

### 其他启动方式

- Windows: 双击运行 `start.bat`
- macOS/Linux: 运行 `./start.sh`

更多详细信息请查看 [DEPLOYMENT.md](DEPLOYMENT.md)
