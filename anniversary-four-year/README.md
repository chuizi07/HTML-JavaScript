# 四周年纪念日

一个沉浸式的全屏翻页式周年纪念网站，包含 8 个页面：

- 锁屏界面：爱心锁图标 + 浮动粒子 + 纪念日密码（0615）解锁，解锁时有光扫过渡动画
- 开场页：标题「我们的第四年」+ 在一起天数
- 时间线页：春夏秋冬四季轮回时间轴
- 四季照片页（4 页）：春·初见 / 夏·热恋 / 秋·收获 / 冬·相守，照片卡片以拍立得风格渐入
- 情书页：打字机效果逐字显示
- 结尾页：「往后余生 都是你」+ 气泡爱心 + 重播按钮

支持触摸滑动、鼠标滚轮、键盘上下键翻页，右侧有导航圆点。Canvas 粒子系统实现漂浮光点和心形汇聚爆发动画。解锁后自动播放背景音乐。

## 自定义

- 密码：修改 `index.html` 中 `LOCK_PASSWORD` 变量
- 照片：替换 `photos/` 目录下的图片
- 音乐：替换 `photos/所念皆星河.mp3`
- 情书内容：修改 `LETTER_TEXT` 变量
